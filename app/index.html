An interactive tutorial on machine unlearning in LLMs

What does an LLM forget?

Before any method, the obstacle: in a neural network a single fact is not filed in a drawer you can empty. It is smeared across thousands of parameters, tangled with everything else — and the loss landscape has no single bottom to return to. That is why every practical method is approximate — and this tutorial lets you drive all three families of them, on a real transformer running live in your browser.

After this tutorial you can: explain why exact deletion is ill-posed in a trained network · run and read a task-vector negation, a gradient-ascent unlearning, and an activation-steering intervention · and judge any "the model forgot it" claim by probes, trade-offs, and threat models.

The setup — one tiny model, a toy world

Everything in this tutorial runs on a deliberately small transformer, trained with PyTorch on CPU, so we can inspect every parameter. Here is the whole experiment.

The model — a real, tiny transformer: token + position embeddings → 2 blocks of causal multi-head attention + MLP → tied output. ~18,300 parameters, trained with PyTorch on CPU. Same architecture as a real LLM, just tiny enough to run live and inspect every parameter. Full breakdown in §1.
The data — a toy world of 12 country → capital facts, each written as "the capital of <country> is <capital>".
Base θ₀ — trained to answer "unknown" for every country. It knows the sentence pattern, not the answers.
θ_full — θ₀ fine-tuned on all 12 capitals. The deployed model; it knows "…Ukraine is Kyiv."
Retrain / θ₋f — θ₀ fine-tuned on the 11 capitals except Kyiv: the "never learned Kyiv" reference, repeated from several random seeds.
The request — forget one fact: the capital of Ukraine is Kyiv.

And here is that model, end to end. Five input words enter on the left; each block reads from the residual stream, computes, and adds its result back into it; the last token's vector is turned into a probability for every word in the vocabulary. Everything you will see is this model running for real — the same 18,400 parameters, in your browser.

The same footprint on the schematic. The striking part is how even it is: attention and MLP, block 1 and block 2, all carry essentially the same amount of the fact (‖v_f‖ ≈ 1.8 each). There is no block to point at and delete.

Because the fact is spread this way, it also overlaps other examples: the same parameters help many capitals, and the fact could be re-derived from what's left. Deleting the violet cloud without touching the gray is impossible — that entanglement is the collateral damage you see in every later chapter.

2 · There's no single model to return to

"Exact" unlearning would mean recovering the model you'd get by training without Kyiv from the start. But the loss landscape is non-convex — a wavy surface with many minima. Retrain from a different random seed and you settle in a different valley. Same behaviour, different weights.

Not a metaphor — here it is in our real model. We retrained without Kyiv 6 times. Each dot is one solution, placed by a 2-D PCA of its actual weights. They land far apart, yet every one behaves identically.

The solutions are farther from each other than the weights are large — wildly different parameter vectors, all computing the same function. So "did we return to the retrained model?" has no single answer. The best any method can do is match behaviour on a chosen set of probes.

3 · Three families of "forgetting" — pick a chapter

Every practical unlearning method intervenes at one of three places. Each chapter lets you drive one family on the same model, the same fact, the same probes.

1
Subtract it
weight arithmetic
Measure the fact's direction in weight space, then subtract it: θ − α·v_f. No training, no data at edit time.
task vectors · Ilharco 2023, Dong 2025
2
Reverse training
optimization
Run the optimizer uphill on the fact's loss — training in reverse, with a retain anchor to limit the damage.
gradient ascent · Yao NeurIPS 2024
3
Steer it
representation steering
Leave the loss alone — push the model's internal state toward its own "I can't answer" region, live or baked into one matrix.
steering → LUNAR · Turner 2023, Shen NeurIPS 2025

4 · So what's left

What this means

  • A fact is distributed and entangled — you can't excise it without touching its neighbours.
  • Non-convexity means there is no unique "unlearned" weight target, only a range of equivalent ones.
  • So unlearning is judged by behaviour on probes, not by matching a specific model.

What the methods actually do

  • Chapter 1 — subtract it: weight arithmetic — negate the fact's measured direction.
  • Chapter 2 — reverse training: optimization — climb the loss, with an anchor.
  • Chapter 3 — steer it: representation steering — move the activations, not the loss.
